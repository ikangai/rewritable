# Seed diet — measured candidates, one built, one deferred, one proposed

**Trigger:** the seed-size ratchet (tests/seed-size.mjs) reads 92% of its
700 KiB budget. Operator asked for the deletion candidates (2026-08-12);
every claim below is measured, not estimated.

## Measured map (2026-08-12, seed at 659,762 bytes)

| Region | Bytes | Verdict |
|---|---|---|
| `//`-comment lines in the bootstrap | ≥ 172.3 KB (26%, 2,268 lines — lower bound, excludes inline/block comments) | §3 proposal |
| Foreign-kind `SYSTEM_PROMPTS` | 15.9 KB per emitted document (workflow alone 13.0 KB) | §1 BUILT |
| Retired lens card (CSS alone) | 5.3 KB | §2 DEFERRED |
| `ARGON2_SRC` (vendored, one line) | 12.8 KB | lives (vault) — not a candidate |
| `RWA_SKIN_RECIPES` | 2.0 KB | not worth touching |
| Legacy CSS aliases | < 1 KB | fold into any future CSS pass |

## §1 — Emission pruning of foreign-kind prompts (BUILT)

`PRODUCT_KIND` is baked at creation; the only lookup is
`SYSTEM_PROMPTS[PRODUCT_KIND] || SYSTEM_PROMPTS.document`. So every emitted
container carried three prompts it could never read.

Mechanism: `workflow`/`presentation`/`workspace` registry entries are wrapped
in `// rwa:kind-prompt:begin/end <kind>` markers in the seed;
`pruneForeignKindPrompts(seed, kind)` (cli/src/seed.mjs, vendored to
service/lib) strips foreign regions at emission. `document` is unmarked and
always ships — it is the universal fallback. Marker asymmetry throws.

Prune sites — every emission path:
- `applySeedSubs` (CLI new/import/clone/upgrade, service `/new`-family, carriers)
- `service/server.js` `/rewritable.html` (raw-template route, prunes lazily via
  the vendored module)
- `tools/regenerate-refs.mjs` document path (bypasses applySeedSubs by design)

The SOURCE seed keeps all kinds — it is the template; the ratchet's budget
still measures the source. What shrank is the per-document tax: **-15,857
bytes per emitted document** (659,762 → 643,905), pinned by
cli/tests/seed-prune.test.mjs (7 cases incl. fail-loud) and the emitted-size
check in tests/seed-size.mjs.

Trade-off accepted: an emitted container can no longer be hand-flipped to
another kind by editing `PRODUCT_KIND` — the foreign prompt is gone. That path
was never supported (kind regions differ anyway); `rwa upgrade` re-emits
through `kindOverrides` and restores the right prompt.

## §2 — Lens card removal (DEFERRED — it is not dead enough)

The card is `display:none`, but 13 live `getElementById('rwa-lens*')` sites
show its elements still serve as functional carriers: `#rwa-lens-progress`
(progress writes), `#rwa-lens-input` (anchored-command flow), `#rwa-lens`
(busy state), `#rwa-lens-hist-panel` (a real Edit-mode surface, hidden only
outside Edit). Removing the card means migrating those onto the pal — a
UI refactor with its own design, not a deletion. Reward today: ~7 KB.
Blocked on that migration; do not "just delete the CSS" — the hist panel and
progress states are reachable.

## §3 — Comment-strip at emission (PROPOSED, needs an operator decision)

The only lever that bends the curve: ≥172 KB of comment lines ship in every
document. The seed is DELIBERATELY self-documenting (agents work inside it),
so deleting comments from the source is wrong. The proposal is emission-time
stripping: the repo seed stays rich; `applySeedSubs` (same chokepoint as §1)
strips `//`-comment lines from the bootstrap before emission.

Costs, stated honestly:
- Breaks "source seed ≈ emitted artifact": `rwa upgrade`'s byte-verify,
  `seedIdentity` semantics (hash the source, stamp the emission — unchanged,
  but the emitted bytes no longer diff cleanly against the seed), and every
  eyeball-diff between a user file and the repo seed.
- A received container becomes less self-explanatory to the next agent that
  opens it — the comments are FOR the fleet. Counterpoint: the fleet works in
  this repo, not in user emissions.
- Needs a robust comment-stripper (template literals with `//` inside —
  a tokenizer-grade problem; the NFC session showed how regexes lie here).

Decision needed: is ~170 KB/document worth a two-artifact world? If yes, this
is its own design doc + a `rwa upgrade` compatibility pass. Until then the
ratchet holds the line at 700 KiB.
